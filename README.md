# 💰 FinanceFlow - Expense Tracker

Aplicación web para gestionar gastos y visualizar hábitos financieros.

## 🚀 Instalación
```bash
git clone https://github.com/NeviumDev/expense-tracker.git
cd expense-tracker
npm install
npm run dev
```

Abre `http://localhost:5173`

## ✨ Características

- Dashboard con gráficos interactivos
- Registro de gastos por categoría
- Filtros por fecha y categoría
- Estadísticas en tiempo real
- Interfaz dark mode premium

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- Recharts
- Lucide React

## 📝 Nota

Los datos son simulados y se reinician al recargar la página. Para producción con persistencia, contactar.
